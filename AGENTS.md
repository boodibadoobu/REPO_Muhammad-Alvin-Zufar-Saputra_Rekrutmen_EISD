# Project Guardrails

Read `PROJECT_CONTEXT.md` before planning or changing this repository. Treat it as
the source of truth for product scope, roles, workflow, database design, UML, and
acceptance criteria.

Do not replace Laravel's conventional Route -> Controller -> Model -> View flow
with an admin generator or automatic CRUD package. Keep migrations, Eloquent
relationships, and the class diagram synchronized whenever the schema changes.

Before declaring work complete, run the automated tests and the verification
steps documented in the README.
